Developed a secure, production-ready ASP.NET Core RESTful API for Student Management designed with clean architecture and modern backend best practices.

Key Highlights:

• Authentication & Authorization: Implemented JWT Token Authentication along with custom Policy-based and Resource-based authorization handlers (Custom Requirement Handlers).

• API Security & Performance: Integrated Rate Limiting middleware to prevent abuse and protect server resources.

• Data Transfer & Architecture: Designed DTOs (Data Transfer Objects) for clean separation between domain models and API endpoints, handling full CRUD operations.

• Interactive Documentation: Configured Swagger/OpenAPI for easy endpoint testing and API exploration.
